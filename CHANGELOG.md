# Changelog

Todas las notas importantes de versiones se documentarán aquí.

## [5.1] - 2026-06-07
### Añadido
- Prototipo de alarma inteligente para ESP32 con pantalla GC9A01A.
- Reloj analógico/digital, alarmas recurrentes y alarmas por fecha.
- Cronómetro, temporizador y tres juegos arcade: Flappy Bird, Asteroids y Runner.
- Control por web y comandos MQTT.
- Panel web integrado con acceso QR.

### Mejorado
- Documentación estructurada para instalación y uso.
- Soporte básico de clima y actualizaciones en pantalla.

### Correcciones
- Se corrigió la documentación del README para reflejar el código actual.
